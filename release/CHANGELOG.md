# Changelog

## 1.0.0 — 2026-10-07
First release: Trepang2 × Minecraft.
- Minecraft Java composited into Trepang2's picture (DirectX 11, ReShade add-on), relit by the scene.
- Focus (slow motion) slows Minecraft's world down too.
- Bullets crack and break Minecraft blocks by hardness; TNT lights when shot; blocks are solid cover in Trepang2.
- Trepang2's grenades, launcher rounds, rockets and mines explode in Minecraft too.
- Zombies and creepers fight Trepang2's NPCs, who shoot back; kicks send mobs flying; cloak hides you from mobs.
- Build mode (NumPad 0) with Minecraft's hotbar and creative inventory.
- Blocktime installer and launcher (EN/RU): finds both games, installs, repairs, uninstalls with backups.
